# プレビュー付きテンプレートbyハイさん
制作者:ハイさん  
  
### ※現在ベータ段階です
ツール→テンプレート→プレビュー付きテンプレートbyハイさんでウィンドウを出せます  
  
## 右上のアイコンの説明  
虫眼鏡マーク:検索欄の表示非表示を切り替えます  
再読み込みマーク:プレビューの再読み込みを行います  
プラスマーク:テンプレートの追加を行います  
歯車マーク:設定を開きます  
ゴミ箱マーク:選択されたテンプレートの削除を行えます(選択を押しているときに表示されるもの)  
エクスポートマーク:選択されたテンプレートのエクスポートを行えます(選択を押しているときに表示されるもの)  
  
適応対象:の先に置かれているアイコン  
スティッキマーク:エフェクトを適応するかのON/OFFを切り替えます(テキスト,エフェクトプリセットのみ)  
AAマーク:フォントを適応するかのON/OFFを切り替えれます(テキストプリセットのみ)  
十字矢印マーク:位置を適応するかのON/OFFを切り替えます(テキスト,エフェクトプリセットのみ)  
拡大マーク:サイズを適応するかのON/OFFを切り替えます(テキストプリセットのみ)  
その他:上記に含まれない設定を適応するかのON/OFFを切り替えます(テキストプリセットのみ)  
  
## 使える機能
テキストプリセット(左上のTマーク)  
エフェクトプリセット(スティッキマーク)  
テンプレート(テンプレートマーク)  
素材ライブラリ(ほぼ完成)(フォルダマーク)  
  
プリセットの並び替え方法:Shift+ドラッグ→入れ替え先にドロップ  
色パターンの並び替え方法:右クリック→パターンの並び替え  
パターンの登録方法1:登録先テンプレートを選択する  
パターンの登録方法2(テキストプリセット限定):テキストアイテムを複数選択して登録  
テキストプリセットの登録:カテゴリやタグを設定した後パターン色を設定、その後保存する内容(位置やフォントなど)を指定して登録します  
エフェクトプリセットの登録:カテゴリやタグ、パターン色を指定した後サムネイルの位置を設定、動画の生成(登録を押したあとでも生成されます)を行い保存に含めないエフェクトをチェックボックスのON/OFFで設定し登録します  
テンプレートの登録:カテゴリやタグ、パターン色を指定したあと登録するアイテムをチェックボックスのON/OFFで設定し、サムネイルの位置を設定、動画の生成(登録を押したあとでも生成されます)を行い登録します  
  
テキストプリセットタブ時適用対象の左側にプレビュー(3文字まで)があります  
3文字までなら自由に設定が可能です  
プレビューの文字が自動的に切り替わります  
パターンの設定変更から親プリセットの変更、選択中のパターンの色を変更が行えます  
エフェクトプリセット及びテンプレートの場合はプレビュー、サムネの再生成も行えます  
パターン色設定のしたのパラメーターを変更することで何番目のエフェクトの色を自動で設定するか変更できます  
右クリックメニューから「選択中のアイテムでパターンを上書き」を行えます  
プリセット設定からプリセット名、カテゴリ、タグを切り替えることができます  
  
設定を開く以下設定を変更できます  
  
簡易表示:プレビューのみの表示にできます(素材ライブラリ対応外)  
表示サイズ:プレビューのサイズを変更できます  
プレビュー背景色:テキストプリセットでの文字の背景を設定できます  
YMM4テンプレート:YMM4のテンプレートから読み込むことができます  
プリセットファイル:このプラグインでエクスポートしたファイルを読み込めます  
プレビュー画像・動画の保存先:エフェクトプリセット、テンプレートのタブで利用しているサムネイルやプレビューの画像を保管している場所の管理を行えます  
素材ライブラリの監視フォルダ:自動で素材ライブラリに追加するフォルダを設定できます
